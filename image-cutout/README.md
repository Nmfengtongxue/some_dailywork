# IMG.LY 抠图编辑器（large，仅本地）

官方 CE.SDK 设计编辑器 + `@imgly/plugin-background-removal-web`，抠图模型为 **large / isnet**（约 176MB，首次从 CDN 下载）。

```bash
cd image-cutout
./start.sh
```

浏览器打开 http://127.0.0.1:5178/  
未申请 license 时导出带 IMG.LY 水印，这是评估模式的正常表现。未做线上部署。
