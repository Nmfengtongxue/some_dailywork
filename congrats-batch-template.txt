# 个检业绩喜报 · 批量输入模板
# --------------------------------------------------
# 规则：
# 1. 每行一条喜报；空行与以 # 开头的行会忽略
# 2. 格式：姓名+下单内容 金额：数字元
# 3. 姓名必须在人员名单中（系统会按部门自动填入）
# 4. 「恭喜：xxx」会按姓名自动生成，无需手写
# 5. 下单内容可自定义，例如：签约团检1单 / 开门红套餐下单 / 618活动套餐下单 / "双11"活动套餐下单
#
# 正确示例（金额后的「元」会写入海报）：
王莉莉+签约团检1单 金额：20000元
陈炳森+开门红套餐下单 金额：15800元
白金玉+618活动套餐下单 金额：9800元
刘倩倩+"双11"活动套餐下单 金额：12800元
#
# 也可用半角冒号：
# 刘倩倩+签约团检2单 金额:12000元
